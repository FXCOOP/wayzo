## 🗄️ Database Schema

### Plans Table

```sql
CREATE TABLE plans (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  title TEXT,
  destination TEXT,
  start_date DATE,
  end_date DATE,
  budget_low INTEGER,
  budget_high INTEGER,
  travelers INTEGER,
  html TEXT,              -- Full trip report HTML
  markdown TEXT,          -- Optional markdown version
  status TEXT DEFAULT 'draft',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_plans_user_id ON plans(user_id);
CREATE INDEX idx_plans_created_at ON plans(created_at DESC);
```

### Row Level Security (RLS)

```sql
-- Users can only see their own plans
CREATE POLICY "Users can view own plans"
  ON plans FOR SELECT
  USING (auth.uid() = user_id);

-- Users can only create their own plans
CREATE POLICY "Users can insert own plans"
  ON plans FOR INSERT
  WITH CHECK (auth.uid() = user_id);
```

## 🐛 Troubleshooting

### Plan Not Saving

**Check browser console for errors:**
- "No access token" → User not authenticated
- "Failed to fetch" → Backend not running
- "403 Forbidden" → RLS policy blocking

**Solutions:**
1. Ensure user is signed in
2. Check Supabase credentials in index.backend.html
3. Verify RLS policies in Supabase

### Dashboard Shows Empty

**Possible causes:**
- User not authenticated
- Plans table empty
- RLS policy blocking query

**Solutions:**
1. Sign in to dashboard
2. Generate a plan first
3. Check Supabase Table Editor → plans table
4. Verify user_id matches auth user

### Plan Doesn't Appear After Generation

**Check these:**
1. Browser console: "✅ Plan saved to database: [UUID]"
2. Supabase Table Editor → plans table → check for new row
3. Dashboard: Refresh page
4. Network tab: Check /api/user/plan POST request status
