🔧 Troubleshooting

❌ Problem: Still asks to sign in after generating plan

Cause: You're signed in on backoffice.html but NOT on main page

Solution:

  1. Sign in on backoffice.html first
  2. Keep that tab open
  3. Open main page in same browser (new tab)
  4. Supabase session should carry over
  5. If not, we need to add sign-in button to main page

❌ Problem: Console shows "User authenticated: false"

Cause: Not signed in with Supabase on that page

Solution:

  1. Go to backoffice.html
  2. Sign in there
  3. Come back to main page and try again
  4. Run checkSupabaseAuth() to verify

❌ Problem: Error "Failed to save plan" or 500 error

Cause: Database schema not created (Step 1 not completed)

Solution:

  1. Go back to Supabase SQL Editor
  2. RUN the SQL code (click ▶ button)
  3. Verify tables exist in Table Editor
  4. Try generating plan again

❌ Problem: Error "Table 'plans' does not exist"

Cause: SQL schema definitely not executed

Solution:

  1. In Supabase SQL Editor
  2. Make sure the SQL code is selected/highlighted
  3. Click the green RUN button (▶)
  4. Wait for "Success" message
  5. Refresh Table Editor to see new tables
